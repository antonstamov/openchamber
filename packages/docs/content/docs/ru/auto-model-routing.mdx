# Автоматическая маршрутизация моделей

Выберите **Авто** в переключателе моделей, и OpenChamber будет выбирать модель для каждого отправляемого запроса. Исправление опечатки уйдёт дешёвой быстрой модели, а сложная ошибка — вашей сильнейшей. Вы один раз решаете в настройках, какая модель занимается каким типом задач.

## Как включить

1. Убедитесь, что настроен [провайдер классификации](/ru/classification-providers/). Для сортировки запросов режиму «Авто» нужен Jev.
2. Откройте **Настройки → Маршрутизация** и включите **Режим «Авто»**.
3. Выберите **Резервную модель** (и её уровень мышления). Пока этого не сделано, «Авто» скрыт.
4. Просмотрите категории ниже и назначьте свои модели тем, которые вам важны.

Когда всё готово, страница сообщает **Готово**. Выберите **Авто** в верхней части переключателя моделей в любой сессии.

## Категории

Каждый запрос попадает в одну категорию. Четыре встроены:

| Категория | Для чего |
| --- | --- |
| Тривиальные | механическая работа: переименования, опечатки, форматирование, комментарии, простые команды |
| Исследование | чтение и объяснение кода без его изменения |
| Реализация | понятное изменение: функция известной формы, тесты, исправление с известной причиной |
| Сложные | ошибки с неизвестной причиной, проектирование и планирование, безопасность, аутентификация, параллельность, миграции, деньги |

Для каждой категории можно задать:

- **Модель:** пусто означает резервную модель
- **Мышление:** уровень мышления для этой модели
- **Агент:** агент, выполняющий такие задачи; пусто оставляет агента, которого выбрал бы редактор сообщений

Jev сортирует запросы, читая названия и описания категорий, поэтому описания работают как инструкции. Пишите, что входит в категорию, а что — нет. Категории можно редактировать, выключать, удалять и добавлять, а встроенную — восстановить, если передумаете. Режиму «Авто» нужны как минимум две включённые категории.

## Что происходит при отправке

1. OpenChamber отправляет Jev ваше сообщение и короткий отрывок из последних нескольких реплик.
2. Jev выбирает категорию и сообщает, насколько уверен.
3. Сессия переключается на модель, уровень мышления и агента этой категории, и ваше сообщение отправляется.

Каждое сообщение сортируется заново, поэтому сессия может перейти с дешёвой модели для быстрого вопроса на вашу сильнейшую для следующего запроса. Редактор продолжает показывать **Авто**, а элементы управления агентом и мышлением скрыты, потому что их определяет категория.

Резервная модель отвечает, когда:

- Jev недостаточно уверен (уверенность ниже 60%)
- Jev не справился или отвечал дольше четырёх секунд
- у категории нет собственной модели

Выбор любой настоящей модели в переключателе выводит сессию из режима «Авто». Выберите **Авто** снова, чтобы вернуться. Также можно сделать «Авто» значением по умолчанию для новых сессий в **Настройки → Сессии**.

## Где это работает

«Авто» выполняется на сервере OpenChamber: в приложении для компьютеров, в веб-приложении и на телефоне, подключённом к любому из них. В VS Code режима «Авто» нет, потому что расширение общается с OpenCode напрямую.
