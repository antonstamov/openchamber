# Инструмент управления агентом

Используйте инструмент агента `openchamber` для управления работой в приложении прямо из чата, а `openchamber_schedule` — для запланированных задач. Оба включены по умолчанию, когда OpenChamber работает на собственном локальном сервере OpenCode; ничего устанавливать не нужно и никаких команд оболочки выполнять не требуется.

## Что можно попросить

Просите агента обычным языком. Например:

- «Создай новую сессию OpenChamber в этом проекте, используй модель `openai/gpt-5.6-sol` и отправь ей этот запрос: проверь поток аутентификации».
- «Создай новую сессию OpenChamber для этой задачи в отдельном рабочем дереве и попроси её добавить тесты для входа в систему».
- «Покажи мои 10 последних сессий OpenChamber вместе с их текущим статусом, используя OpenChamber».
- «Создай в OpenChamber запланированную задачу с именем Weekday review, которая отправляет этот запрос в 09:00 по будням: проверь изменения с прошлого запуска».
- «Запусти сейчас запланированную задачу OpenChamber с именем Weekday review».
- «Проверь сессию OpenChamber с именем Authentication review и покажи мне её последний ответ ассистента».

Инструмент управления может перечислять проекты и предпочтения моделей, искать в каталоге моделей, создавать сессии и обращаться к ним повторно, ответвлять сессию и создавать изолированные сессии в рабочих деревьях. Инструмент планирования создаёт, изменяет, запускает, приостанавливает и удаляет запланированные задачи. Сессии, запущенные таким образом, появляются в OpenChamber как любые другие, поэтому их можно открыть и продолжить работу самостоятельно.

## Что стоит помнить

- Запросы на создание сессий возвращаются сразу по умолчанию. Следите за сессией в OpenChamber или попросите агента проверить её позже.
- Отдельное рабочее дерево создаётся, только если вы об этом попросили. Незафиксированные изменения из текущего рабочего дерева в него не копируются.
- Когда рабочее окружение выглядит занятым, например другая сессия работает на той же ветке, агент может предложить перенести свою сессию в новое рабочее дерево. Перенос происходит после вашего согласия, и переносятся только изменённые им файлы.
- Инструменты не могут удалять сессии или рабочие деревья, регистрировать пути проектов, выполнять произвольные команды оболочки или обращаться к произвольным URL.

## Как включить или выключить инструменты

Откройте **Настройки → Общие → Инструменты OpenChamber** и измените **Инструмент управления агентом** или **Инструмент планирования агента**; каждый переключается отдельно. Если вы выключали инструмент управления до того, как планирование стало отдельным инструментом, инструмент планирования тоже начнётся выключенным. Изменение доходит до работающих сессий на их следующем шаге, без перезапуска. Если в вашем окружении уже задана переменная `OPENCODE_CONFIG`, она применяется после перезапуска управляемого сервера OpenCode.

Инструменты недоступны, когда OpenChamber подключается к внешнему серверу OpenCode через `OPENCODE_HOST` или пропуск запуска, а также внутри расширения VS Code. Установки для компьютеров и веба, использующие управляемый сервер OpenCode от OpenChamber, поддерживают их автоматически.
