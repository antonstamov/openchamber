# Навыки

Навык — это переиспользуемый набор инструкций, который агент может подтянуть, когда он релевантен — например, «как мы пишем сообщения коммитов» или «наши соглашения по API». Управляйте ими в **Настройки → Навыки**.

Чтобы установить готовые навыки вместо написания своих, см. [Skills Catalog](/ru/skills-catalog/).

## Создание навыка

1. Откройте **Настройки → Навыки**.
2. Создайте навык и дайте ему имя и короткое описание. Именно по описанию агент решает, когда навык применим, поэтому сделайте его конкретным.
3. Напишите инструкции. Добавьте вспомогательные файлы, если навыку они нужны.
4. Выберите, где он живёт:
   - **personal** — доступен в каждом проекте
   - **project** — доступен только в текущем проекте

## Использование навыка в чате

Введите `$` в любом месте сообщения, включая начало, чтобы вызвать выбор навыка, затем выберите его. Агент подгрузит инструкции этого навыка для ответа.

`/` в самом начале сообщения открывает [команды](/ru/chat-input/), в которые навыки не входят.
