# Подключение устройства

Подключите другое устройство — мобильное приложение, приложение для компьютеров или браузер на другой машине — к вашему серверу OpenChamber, отсканировав одноразовый QR-код. Это рекомендуемый способ подключения устройств; не нужно открывать порты и вводить адреса.

## Как подключить устройство

1. На машине с OpenChamber откройте **Настройки → Удалённые инстансы → Подключение к этому серверу** и нажмите **Добавить устройство**.
2. Дайте устройству имя (например, *Мой iPhone*), чтобы потом его узнавать.
3. Выберите, где будете использовать устройство:
   - **Только этот компьютер** — для приложений, работающих на этой же машине
   - **Только домашняя сеть** — прямое подключение по вашему Wi-Fi; вне этой сети не работает
   - **Где угодно** — работает дома и вне дома; трафик вне дома идёт через [приватный релей](/ru/private-relay/) — сквозной шифрованный туннель без настройки
4. Нажмите **Создать QR-код**.
5. На другом устройстве отсканируйте код:
   - **мобильное приложение** — нажмите **Сканировать QR-код** на экране подключения (или в списке инстансов)
   - **приложение для компьютеров** — вместо этого скопируйте ссылку подключения и откройте её на машине с приложением для компьютеров, которое спросит подтверждения перед подключением. Её также можно вставить в **Настройки → Удалённые инстансы → Другие серверы OpenChamber → Импорт ссылки**

Диалог закроется сам, как только устройство подключится, и устройство появится в списке с живым статусом. Вот и всё — вы подключены.

## Как подключение остаётся безопасным

- **QR-код одноразовый.** Он перестаёт работать в момент, когда устройство его использует, и сам истекает, если им не воспользовались.
- **Каждое устройство получает собственный токен.** Сканирование кода никогда не раскрывает ваш пароль интерфейса, а токен одного устройства нельзя использовать для выдачи себя за другое.
- **Вы всё контролируете.** Каждое подключённое устройство перечислено с именем, платформой и статусом подключения — любое из них можно отозвать в любой момент.
- **Трафик вне дома шифруется сквозным шифрованием.** С вариантом **Где угодно** трафик вне вашей сети идёт через [приватный релей](/ru/private-relay/), который не может читать проходящее через него.

## Управление подключёнными устройствами

**Настройки → Удалённые инстансы → Подключение к этому серверу** перечисляет каждое устройство, которое может обращаться к этому серверу, с зелёной точкой, когда оно в сети, и указанием, подключено ли оно по локальной сети или через релей.

- **Отозвать** немедленно отключает устройство. Подключите его заново новым QR-кодом, если передумаете.
- **Очистить отозванные** прибирает список.

Одно и то же физическое устройство сохраняет одну запись, даже если войдёт позже снова, — дубликаты не накапливаются.

## Подключение из командной строки

Если сервер работает без интерфейса (UI не открыт), создайте ссылку подключения из терминала на этой машине.

Для устройства в той же сети:

```bash
openchamber connect-url --port 3000 --qr
```

Для устройства, которое должно подключаться **отовсюду** — аналог выбора **Где угодно** в диалоге:

```bash
openchamber connect-url --relay --qr
```

Ссылка с `--relay` несёт оба маршрута, как и диалог: устройство подключается напрямую по локальной сети, когда может достичь сервера, и переключается на [приватный релей](/ru/private-relay/), когда оно вне дома. Релей стартует сам: работающий инстанс подхватывает ссылку в течение минуты, остановленный — при следующем запуске.

> Прямой маршрут работает, только если сервер действительно слушает вашу сеть. По умолчанию OpenChamber слушает только саму машину — запустите его с `--lan`, чтобы он стал доступен по Wi-Fi. Команда предупреждает вас (`[LAN_UNREACHABLE]`), когда прямой маршрут ссылки не будет работать с других устройств; ссылка с `--relay` при этом всё равно работает, только всегда через релей.

Напечатанная ссылка и QR-код работают точно так же, как из диалога настроек — одноразовые, с истечением, отзываемые.

Чтобы подключить приложение для компьютеров, откройте напечатанную ссылку на машине, где работает это приложение. Приложение попросит подтверждения, затем подключится. На macOS:

```bash
open 'openchamber://connect?v=2&p=...'
```
