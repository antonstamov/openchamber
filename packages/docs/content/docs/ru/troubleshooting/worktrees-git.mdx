# Worktree и Git

Проблемы, возникающие с [сессиями в worktree](/ru/worktrees/) и [представлением git](/ru/git/), и как их устранить.

## Worktree требует внимания

OpenChamber помечает worktree, когда что-то не так:

- **папка отсутствует** — папка worktree была удалена или перемещена вне OpenChamber; удалите сессию и создайте свежий worktree
- **detached- или unborn-ветка** — worktree не на обычной ветке; выгрузите его на обычную
- **merge, rebase или cherry-pick в процессе** — операция осталась наполовину завершённой; завершите или прервите её из представления git

## Не получается создать worktree

- **ветка уже существует** — выберите другое имя ветки или используйте вариант с существующей веткой
- **имя уже используется** — выберите другое имя worktree

## Генерация коммита или PR не удаётся

Генерация сообщения коммита или описания PR выполняется в вашей активной сессии, поэтому нужна открытая сессия с выбранной рабочей моделью. Откройте или выберите сессию и попробуйте снова.

## Проблемы SSH или путей Windows

- убедитесь, что SSH-ключ, используемый репозиторием, — тот, что задан в вашем [git-удостоверении](/ru/git-identities/)
- в Windows git использует пути в стиле Unix (вроде `/c/Users/...`) — OpenChamber это обрабатывает, но пользовательские пути SSH-ключей должны следовать той же форме
