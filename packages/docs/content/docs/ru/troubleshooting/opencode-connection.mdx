# Подключение OpenCode

Если OpenChamber загружается, но никогда не выходит из состояния «OpenCode перезапускается», или чат не отвечает, сервер, с которым он говорит, недоступен. Пройдите по этим пунктам.

## Застряло на «OpenCode перезапускается»

- подождите немного сразу после запуска — это состояние нормально, пока сервер стартует
- проверьте, жив ли сервер, командой `openchamber status`
- перезапустите его командой `openchamber restart`
- посмотрите детали запуска командой `openchamber logs`

## Вы подключаетесь к собственному серверу

Если вы настроили OpenChamber на использование существующего сервера, перепроверьте настройку из [Сервера OpenCode](/ru/opencode-server/):

- `OPENCODE_HOST` должен включать порт, без пути — например `http://localhost:4096`
- задайте `OPENCODE_SKIP_START=true`, чтобы OpenChamber не запускал ещё и свой
- если адрес неверен, OpenChamber игнорирует его и запускает собственный сервер — ищите предупреждение `[config]` в логах

## Всё ещё не работает

- убедитесь, что версия Node.js — `24.14` или новее
- переустановите последнюю версию CLI
- откройте `http://localhost:3000` напрямую, прежде чем проверять туннель или удалённую ссылку
