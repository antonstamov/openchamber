# Обновления

Способ обновления OpenChamber зависит от способа установки. В любом случае текущую версию можно проверить в разделе **Настройки → OpenChamber → О программе**.

## Десктопное приложение

Десктопное приложение проверяет обновления по релизам GitHub. Когда обновление доступно, OpenChamber сообщает вам, загружает его по вашему выбору и устанавливает при следующем перезапуске. Вы всегда всё контролируете — ничего не устанавливается без вашего согласия.

## Веб / CLI

Если вы установили CLI, обновите его из раздела **О программе** с помощью кнопок проверки и обновления или из терминала:

```bash
openchamber update
```

OpenChamber определяет способ установки (npm, pnpm, yarn или bun) и выполняет нужное обновление за вас.

## Сервер OpenCode

OpenChamber и OpenCode обновляются отдельно. Когда доступна новая версия OpenCode, OpenChamber предлагает обновить её и после этого перезапускает сервер. См. [Сервер OpenCode](/ru/opencode-server/) о том, как управляется этот сервер.
