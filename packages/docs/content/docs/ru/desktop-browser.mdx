# Панель браузера

Панель браузера открывает любую страницу рядом с вашим чатом. Откройте её кнопкой с глобусом в шапке приложения.

В приложении для компьютеров это настоящий браузер: ваши входы сохраняются, горячая перезагрузка работает, а инструменты разработчика — в одном клике. Во вкладке веб-браузера панель тоже может показать страницу, но не может заглянуть внутрь неё — инструменты разметки ниже работают только на компьютере. В расширении VS Code панели браузера нет вовсе: VS Code уже является редактором с браузером рядом, а всё, ради чего эта панель ценна, требует приложения для компьютеров.

Открытым здесь страницам недоступны ваши камера, микрофон и местоположение: такие запросы отклоняются.

Копирование и вставка используют буфер обмена компьютера на macOS, Windows и Linux. Страница
должна быть в фокусе, чтобы копировать. Чтение буфера через JavaScript работает только
для страницы в фокусе на буквальном имени хоста `localhost`. Страницы, открытые через
туннель удалённой разработки, внешние страницы и страницы по адресам `127.0.0.1` или
`[::1]` не могут читать буфер. Обычная вставка продолжает работать после фокуса на поле. В веб-версии и версии VS Code этого браузера и его поведения буфера нет.

## Панель инструментов

Адресная строка запоминает страницы, открытые вами в этом проекте, и предлагает их по мере ввода, совпадая с частью адреса или заголовка страницы. Стрелки перемещаются по списку, Enter открывает выделенную запись, а кнопка на строке удаляет её.

**Перезагрузить** — рядом с ней, вместе с **жёсткой перезагрузкой**, игнорирующей кеш, когда изменение отказывается показываться, и элементами масштаба, масштабирующими только страницу.

**Очистить cookie** и **Очистить кешированные данные** применяются только к этой панели. Ваша сессия OpenChamber и любое другое окно не затрагиваются.

## Разметка страницы

Нажмите **Разметить**, и поверх страницы появится панель с тремя инструментами:

- **Элемент** — кликните элемент. Клик по другому перемещает выделение; повторный клик по тому же снимает его.
- **Область** — обведите рамкой зону, когда имеете в виду больше одного элемента.
- **Рисунок** — рисуйте от руки поверх страницы.

Напишите желаемое в поле, появляющемся рядом с пометкой, и нажмите **Прикрепить** — или просто Enter. Ваше сообщение в чате получит карточку со всеми пометками, вашей заметкой и скриншотом видимой страницы с нарисованными пометками — так можно сказать «эта кнопка, чуть круглее», вместо того чтобы описывать, где она.

Сама страница никогда не изменяется — разметка лишь отмечает то, что есть. `Esc` отменяет и закрывает панель.

## Пусть агент управляет

Агент может сам пользоваться панелью браузера — открывать страницу, читать содержимое, кликать, вводить текст, прокручивать и переключаться между мобильным, планшетным и компьютерным видами, — чтобы проверять собственную работу, не спрашивая вас. Вы увидите это в панели.

Агент не может выполнять произвольный код на странице. В браузере хранятся ваши настоящие входы, поэтому он ограничен перечисленными выше действиями.

Он также может сохранить снимок того, на что смотрит, в `.openchamber/screenshots/` в вашем проекте и показать его вам в ответе. Именно так становится возможным «до и после», а файл остаётся там и потом — его можно приложить к запросу на слияние.

Действия браузера — это **инструмент OpenChamber Web**, который включается и выключается отдельно в **Настройки → Общие → Инструменты OpenChamber**.

Для этого нужно приложение для компьютеров: страницей, показанной во вкладке веб-браузера, управлять нельзя.

### Провайдер браузера

Расширение может подменить здесь приложение для компьютеров. То, которое объявляет провайдера браузера, запускает собственный браузер на сервере OpenChamber и отвечает на те же действия, чтобы агент мог просматривать страницы, когда приложение для компьютеров не открыто, например на удалённом сервере. Выберите его в **Настройки → Общие → Инструменты OpenChamber → Провайдер браузера**; без установленного такого расширения список показывает только «OpenChamber Web» и отключён. Выбор применяется к следующему действию браузера. Если это расширение приостановлено или удалено, снова используется OpenChamber Web, а всплывающее уведомление сообщает об этом. Авторам расширений: см. `GUEST_SERVICES.md` в пакете SDK.

## Размер и внешний вид

Нажмите кнопку телефона, чтобы открыть панель устройств. Выберите пресет или введите ширину и
высоту, и страница будет свёрстана под этот размер — уменьшенная, чтобы поместиться в панель,
когда она больше, но всё равно измеряющая себя в запрошенном размере.

Та же панель принудительно включает светлую или тёмную тему страницы, чтобы тему можно было проверить, не
меняя ничего на вашей машине. Инструменты разработчика она не трогает; к странице может быть подключён только один отладчик, поэтому сначала закройте DevTools, если они открыты.

## Инструменты разработчика

Нажмите кнопку терминала на панели инструментов, чтобы открыть собственные инструменты разработчика Chromium для страницы — консоль, сеть, элементы, всё ожидаемое.
