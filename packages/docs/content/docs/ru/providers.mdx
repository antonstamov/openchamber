# Провайдеры, модели и агенты

Прежде чем OpenChamber сможет что-либо делать, нужно подключить хотя бы одного ИИ-провайдера. На этой странице — подключение провайдера, выбор модели и настройка агентов.

## Подключение провайдера

1. Откройте **Настройки → Провайдеры**.
2. Откройте меню **Add provider** и выберите провайдера, который ещё не подключён, или выберите **Other / Custom** для OpenAI-совместимой точки доступа.
3. Войдите одним из двух способов, в зависимости от провайдера:
   - **API key** — вставьте ключ и сохраните.
   - **Sign-in (device flow)** — OpenChamber покажет ссылку и короткий код. Откройте ссылку, введите код и подтвердите. OpenChamber завершит подключение самостоятельно.

### Пользовательские / другие провайдеры

Для шлюзов, университетских LLM, Ollama, LiteLLM и подобных OpenAI-совместимых API:

1. Выберите **Other / Custom** в списке провайдеров.
2. Введите ID провайдера, отображаемое имя, базовый URL (`http://` или `https://`), API-ключ (или `{env:VAR_NAME}`) и хотя бы один ID/имя модели.
3. При желании перечислите уровни рассуждений модели (например `low, medium, high`). Каждый уровень появится в выборе варианта модели в чате, как и для встроенных провайдеров.
4. При желании добавьте заголовки запросов.
5. Сохраните — OpenChamber запишет блок провайдера в конфиг OpenCode, а ключ сохранит в авторизации OpenCode (буквальные ключи) или запишет ссылку `{env:VAR}`.
6. Чтобы изменить существующего пользовательского провайдера, откройте его и выберите **Edit**.

Пользовательским провайдерам нужен API-ключ или `{env:VAR_NAME}`, иначе они не будут считаться полностью подключёнными. Без учётных данных модели могут отображаться, но вызовы чата завершатся ошибкой.

Когда провайдер отображается как подключённый, его модели становятся доступны в чате.

Чтобы отключиться, откройте провайдера и удалите его вход.

## Выбор модели

Модель выбирается там, где вы работаете:

- в чате используйте выбор модели в панели сообщения, чтобы задать провайдера и модель для этой сессии
- для каждого агента задайте модель по умолчанию (ниже)

## Настройка агентов

Агент — это именованная конфигурация: модель, характер и разрешённые действия.

1. Откройте **Настройки → Агенты**.
2. Выберите агента или создайте нового.
3. Измените любое из:
   - **description** — для чего нужен агент
   - **model** — его модель по умолчанию
   - **temperature** — насколько творческими будут ответы
   - **prompt** — постоянные инструкции, которым он всегда следует
   - **tool rules** — какие инструменты ему можно использовать

## Где хранятся ваши входы

Входы провайдеров хранит OpenCode, а не OpenChamber, поэтому они общие с OpenCode CLI. Если один и тот же провайдер настроен в нескольких местах, побеждает наиболее конкретная настройка: настройка для проекта переопределяет личную.
