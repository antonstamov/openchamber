# Мульти-запуск

Мульти-запуск запускает несколько сессий из одной формы — удобно, чтобы попробовать одну задачу на разных моделях и сравнить результаты. Откройте его из выбора модели в композиторе (**Запустить на нескольких моделях**) или из палитры команд (**Запустить параллельно**).

## Запуск мульти-запуска

1. Откройте лаунчер мульти-запуска.
2. Выберите проект и назовите группу запусков.
3. Напишите промпт и выберите модели для запуска.
4. Выберите, **изолировать ли запуски**.
5. Запустите.

Каждая модель получает собственную сессию, и все стартуют с вашего промпта.

## Изолированные запуски

Включите **изолировать запуски**, чтобы дать каждому запуску собственное [worktree](/ru/worktrees/) и ветку, тогда они никогда не трогают одни файлы. Для этого нужен git-репозиторий — для папок без него опция выключается автоматически. Выберите ветку, с которой стартуют запуски.

Без изоляции каждый запуск — обычная сессия в папке проекта.

## Сравнение результатов

Каждый запуск — обычная сессия, которую можно открыть, прочитать и оставить или отбросить. Если вы запустили их для сравнения подходов, просмотрите их рядом и продолжите с лучшим.

Если один запуск не стартовал, остальные всё равно запустятся — вы просто увидите меньше сессий, чем просили.
