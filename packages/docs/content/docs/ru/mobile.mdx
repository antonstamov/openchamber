# Мобильные приложения и PWA

У OpenChamber есть нативные приложения для iPhone и Android, чтобы вы могли следить за сессиями, отвечать агентам и управлять работой с телефона — дома по Wi-Fi или откуда угодно через [Приватный релей](/ru/private-relay/).

## Установка приложения

- **iPhone/iPad** — присоединитесь к [бете TestFlight](https://testflight.apple.com/join/5ek6GU1E)
- **Android** — скачайте APK из [ночной сборки Canary](https://github.com/openchamber/openchamber/releases/tag/canary)

## Подключение к вашему серверу

1. На компьютере с OpenChamber откройте **Настройки → Удалённые инстансы → Подключиться к этому серверу** и нажмите **Добавить устройство**.
2. Выберите **Везде** (или **Только домашняя сеть**, если будете пользоваться телефоном только дома) и нажмите **Создать QR-код**.
3. В мобильном приложении нажмите **Сканировать QR-код** и наведите камеру на него.

Приложение подключается и запоминает сервер. QR-код одноразовый, и каждое устройство получает собственный отзываемый токен — как устроена безопасность связывания, см. в разделе [Подключение устройства](/ru/connect-devices/).

Приложение можно связать с несколькими серверами и переключаться между ними из списка инстансов; для каждого показано, доступен ли он и подключены ли вы по локальной сети или через релей.

## PWA (установка из браузера)

Не хотите никаких магазинов приложений? Веб-приложение устанавливается прямо из браузера:

- **десктопный браузер** — используйте опцию **Установить** в адресной строке
- **iPhone/iPad (Safari)** — Поделиться → **На экран «Домой»**
- **Android (Chrome)** — меню → **Установить приложение** / **Добавить на главный экран**

Чтобы добраться до PWA извне вашей сети, понадобятся [туннель](/ru/tunnels/) и надёжный [пароль интерфейса](/ru/security/) — нативные приложения решают это за вас через релей.

## Мобильные настройки

В разделе **Настройки → OpenChamber** несколько опций настраивают мобильный и установленный опыт — установленное имя приложения, ориентацию экрана и поведение экранной клавиатуры.
