# SSH-хосты и проксирование

Используйте **Настройки → Удалённые инстансы** в десктопном приложении, чтобы импортировать сохранённые SSH-хосты, подключаться к удалённой машине и делать дополнительные порты доступными через то же SSH-соединение.

> SSH-хосты и SSH-проксирование — функции **только десктопа**. Они используют SSH-клиент вашего компьютера.

## Импорт SSH-хоста

OpenChamber умеет читать хосты из вашего локального SSH-конфига, того же, что используют команды вроде `ssh work-server`.

1. Откройте **Настройки → Удалённые инстансы**.
2. Выберите хост в **Saved SSH hosts**.
3. Если хост — шаблон, введите реальное назначение, например `deploy@app.example.com`.
4. Сохраните и подключитесь.

OpenChamber создаёт удалённый инстанс с помощью этой SSH-команды. Когда он достигает **ready**, удалённый интерфейс OpenChamber открывается в десктопном приложении.

## Дополнительные пробросы портов

У каждого удалённого инстанса есть раздел **Port Forwards**. Используйте его, когда чему-то на одной стороне SSH-соединения нужно достать до порта на другой стороне.

OpenChamber поддерживает три типа пробросов:

- **Local (-L)** — открыть порт на вашем компьютере, ведущий к чему-то на удалённой машине.
- **Remote (-R)** — открыть порт на удалённой машине, ведущий обратно к вашему компьютеру.
- **Dynamic (-D)** — открыть локальный SOCKS-прокси через SSH-соединение.

Для большинства превью приложений и дашбордов, работающих на удалённой машине, используйте **Local (-L)**.

## Использование SOCKS-прокси

Выбирайте **Dynamic (-D)**, когда хотите, чтобы другие инструменты на вашем компьютере ходили в интернет через удалённую машину. OpenChamber открывает локальный SOCKS-прокси порт для этого SSH-соединения.

После готовности соединения скопируйте или используйте локальный адрес прокси из строки проброса. Настройте браузер или инструмент использовать его как SOCKS5-прокси.

## Сохраняйте приватность

Используйте `127.0.0.1` или `localhost` для локальных bind-хостов, если только вы намеренно не хотите, чтобы проброшенный порт был доступен другим устройствам в вашей сети.
