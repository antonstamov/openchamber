# Устранение неполадок

Что-то пошло не так? Найдите симптом ниже и попробуйте решение.

## Команда OpenChamber завершается или не запускается

- проверьте Node.js `>=24.14`
- выполните `openchamber --version`
- при необходимости переустановите последнюю версию CLI

## Веб-интерфейс недоступен

- проверьте логи сервера командой `openchamber logs`
- проверьте активный порт (по умолчанию `3000`)
- сначала откройте `http://localhost:3000` напрямую, прежде чем проверять ссылки туннеля

## Ссылка удалённого доступа/туннеля не работает

- выполните `openchamber tunnel status --all`
- перезапустите туннель из того же экземпляра/порта
- создайте ссылку для подключения заново, если предыдущий токен уже был использован

См. [Туннели](/ru/tunnels/) для полной настройки и [Обратный прокси](/ru/reverse-proxy/), если вы его используете.

## Расширение VS Code не подключается

- убедитесь, что сервер OpenChamber запущен
- проверьте, что расширение обновлено
- перезагрузите окно VS Code и повторите подключение
