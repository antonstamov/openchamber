# Каталог навыков

Каталог навыков позволяет устанавливать навыки, опубликованные другими людьми, вместо того чтобы писать свои. Откройте его в **Настройки → Навыки → Каталог**.

О написании собственных навыков см. [Skills](/ru/skills/).

## Установка навыка

1. Откройте каталог.
2. Просмотрите встроенные источники — например, репозиторий навыков Anthropic — или поищите.
3. Выберите навык и установите его.
4. Выберите, куда установить: для всего, что вы делаете, или только для текущего проекта.

Если навык с тем же именем уже существует, OpenChamber спрашивает, что делать — пропустить его, перезаписать или решить по каждому.

## Добавление собственного источника

Источником можно сделать любой Git-репозиторий, указав его имя `owner/repo` или полный Git-URL. Приватным репозиториям нужен настроенный на вашей машине доступ (SSH-ключ или сохранённые учётные данные); если источник не аутентифицируется, каталог так и сообщает, а не молча проваливается. Чтобы использовать ветку или тег, отличный от стандартного, добавьте его через `#`: `owner/repo#develop` или `https://github.com/owner/repo.git#v1.0.0`.
