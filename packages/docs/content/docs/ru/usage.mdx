# Использование и квоты

Страница использования показывает, какая часть плана каждого провайдера уже израсходована, чтобы вы видели, насколько близки к лимиту. Откройте её в разделе **Настройки → Использование**.

## Что вы видите

Для каждого подключённого провайдера OpenChamber показывает:

- сколько текущего окна уже израсходовано, в виде полосы
- разбивку по моделям
- индикатор темпа, чтобы понять, хватит ли лимита

Вы можете выбрать, какие провайдеры отображать, и та же сводка доступна из раскрывающегося списка в шапке приложения.

## Поддерживаемые провайдеры

Использование работает для провайдеров, публикующих квоту, включая Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud и Wafer.

Провайдер показывает использование только после входа в него на странице [Провайдеры](/ru/providers/). Некоторым провайдерам нужен собственный credential, который вводится в настройках использования — это exe.dev, Cursor и ZenMux. Если провайдер не показывает данных, обычно это означает, что credential отсутствует.
