# Превью и dev-серверы

Когда вы запускаете dev-сервер, OpenChamber может открыть его прямо внутри приложения вместо отдельной вкладки браузера — чтобы видеть сайт рядом с чатом и указывать на элементы, задавая вопросы.

## Открытие dev-сервера

Откройте панель браузера кнопкой-глобусом в заголовке приложения. Если dev-сервер уже запущен, он там перечислен, и один клик его открывает — OpenChamber находит его по тому, что реально слушает на вашей машине, поэтому работает независимо от способа запуска.

Dev-сервер также открывается автоматически, когда:

- вы нажимаете **Открыть превью** на локальном адресе в терминале
- [действие проекта](/ru/project-actions/) с включённым авто-открытием запускает его
- вы переходите по локальной ссылке в сообщении чата

Адрес всегда можно ввести вручную. Голый `localhost:5173` считается `http://`, поэтому схему вводить не обязательно.

## Работа с удалённым OpenChamber

Когда OpenChamber работает на другой машине, его dev-сервер находится *на той* машине — `localhost` на вашем ноутбуке оказывается совсем в другом месте. Десктопное приложение решает это за вас: оно открывает локальный порт, несущий соединение до удалённого dev-сервера, поэтому страница грузится нормально, с работающей горячей перезагрузкой и инструментами разработчика. Вы продолжаете вводить ожидаемый адрес; детали остаются за кадром.

Для этого нужно десктопное приложение. Во вкладке веб-браузера открываются только dev-серверы на вашей собственной машине.
