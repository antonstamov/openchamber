# Туннели на компьютере

Приложение для компьютеров может создать туннель в **Настройки → OpenChamber → Туннель**. Для этого пути не нужно запускать OpenChamber из CLI.

## Установите провайдера

OpenChamber запускает CLI провайдера на вашей машине. Сначала установите нужного провайдера:

```bash
brew install cloudflared
brew install ngrok
```

Cloudflare использует `cloudflared`. Ngrok требует учётной записи ngrok и токена из панели ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

Для Tailscale установите [приложение Tailscale](https://tailscale.com/download) и войдите.

## Запуск из приложения

1. Откройте **Настройки → OpenChamber → Туннель**.
2. Выберите **Cloudflare**, **Ngrok** или **Tailscale**.
3. Выберите тип туннеля и нажмите **Запустить туннель**.
4. Отсканируйте сгенерированный QR-код телефоном.

Ngrok сейчас поддерживает быстрые туннели. Cloudflare поддерживает быстрые туннели и управляемые режимы Cloudflare. Tailscale предлагает **Serve**, который открывают только устройства в вашей tailnet, и **Funnel**, который может открыть любой в интернете. Если Tailscale сначала требует включить HTTPS или Funnel для вашей tailnet, рядом с ошибкой появится кнопка **Открыть страницу подтверждения**; подтвердите там и запустите снова.

## Защита доступа

Даже когда сам URL провайдера публичный, OpenChamber всё равно защищает доступ собственным токеном подключения. Сгенерированная ссылка подключения содержит одноразовый токен, имеет TTL, а старые неиспользованные ссылки отзываются, когда вы генерируете новую или останавливаете/перезапускаете туннель.
