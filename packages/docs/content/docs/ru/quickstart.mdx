# Быстрый старт

## Самый быстрый путь

1. Установите [OpenCode](https://opencode.ai).
2. Установите OpenChamber CLI (однострочную команду см. в [Install](/ru/install/)).
3. Выполните `openchamber --ui-password be-creative-here`.
4. Откройте URL, который выведет CLI (обычно `http://localhost:3000`).
5. Чтобы пользоваться с телефона, запустите [туннель](/ru/tunnels/) и отсканируйте QR-код.

Вы должны увидеть список сессий OpenChamber в браузере. Если он загрузился, всё работает.

Используйте надёжный пароль интерфейса, особенно если планируете открыть инстанс в интернет.

Если страница не загружается, см. [Troubleshooting](/ru/troubleshooting/).

## Какое приложение использовать?

- **десктоп** — для повседневной работы на macOS, Windows или Linux
- **веб** — для удалённого доступа и просмотра с телефона
- **VS Code** — для сессий рядом с кодом
