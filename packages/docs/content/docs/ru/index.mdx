# Документация OpenChamber

OpenChamber — это визуальное рабочее место вокруг OpenCode (агента для программирования с ИИ, работающего в вашем терминале). Оно даёт экран, чтобы наблюдать за этой работой и направлять её, вместо жизни в командной строке.

Используйте эту документацию, чтобы:

- установить подходящее приложение для вашей работы
- открыть OpenChamber для безопасного удалённого использования
- настроить внешний вид и исправить частые проблемы

## Для чего нужен OpenChamber

OpenChamber — для тех частей программирования с ИИ, которым идёт на пользу диспетчерская: ветвящиеся сессии, просмотр diff, управление терминалами, наблюдение за прогрессом инструментов, запуск действий проекта и удержание всей доски на виду, пока агент работает.
