# Удалённые инстансы

Десктопное приложение может подключаться к OpenChamber, работающему на другой машине по SSH — рабочему серверу, облачной машине, домашнему серверу — и показывать его интерфейс так, будто он локальный. Настройка находится в **Настройки → Удалённые инстансы**.

> Удалённые инстансы — функция **только десктопа**. В вебе или в VS Code подключайтесь к удалённому серверу через переменные окружения из [OpenCode Server](/ru/opencode-server/).

## Добавление удалённого инстанса

1. Откройте **Настройки → Удалённые инстансы** и добавьте новый.
2. Укажите SSH-команду, которой вы обычно подключаетесь к машине, и nickname.
3. Выберите, как OpenChamber работает там:
   - **managed** — OpenChamber сам установится и запустится на удалённой машине
   - **external** — подключение к уже запущенному
4. Подключитесь.

OpenChamber проходит шаги по порядку — проверка соединения, настройка удалённой стороны, запуск сервера и проброс порта — и показывает, на каком этапе находится. Когда достигнут статус **ready**, удалённый интерфейс загрузится локально.

## Учётные данные

Вы решаете, сохранять ли SSH-пароль и пароль интерфейса или вводить их каждый раз. Если соединение обрывается, OpenChamber сообщает, какой шаг не удался, чтобы вы могли это исправить — см. [Remote access](/ru/troubleshooting/remote-access/).

## Ссылки для подключения

Если на удалённой машине уже работает OpenChamber, проще всего подключить десктопное приложение ссылкой для сопряжения. В интерфейсе удалённого сервера откройте **Настройки → Удалённые инстансы → Connect to this server → Add a device**, создайте ссылку и импортируйте её на десктопе в **Настройки → Удалённые инстансы → Other OpenChamber servers → Import Link**. Полный процесс см. в [Connect a Device](/ru/connect-devices/).

Ссылка, созданная с вариантом **Anywhere**, несёт и прямой адрес, и маршрут через [Private Relay](/ru/private-relay/): десктоп подключается напрямую, когда сервер доступен (та же сеть), и переключается на сквозной зашифрованный релей, когда вы вне дома. Статус рядом с каждым сохранённым сервером показывает, какой маршрут используется.

Ссылку можно также создать из терминала на удалённой машине:

```bash
openchamber connect-url --port 3000 --server http://your-host:3000 --qr
```

`connect-url` сначала запускает сервер, если на этом порту ничего не работает. Добавьте `--api-only` для headless-сервера, `--lan` для привязки к LAN при запуске, `--ui-password` для защиты доступа из браузера и `--name` для подписи сохранённого подключения. Добавьте `--relay` для ссылки, работающей и вне локальной сети: устройство предпочитает прямое подключение, когда оно доступно, и переключается на [Private Relay](/ru/private-relay/) — инстанс сам поднимает релей.

Сгенерированная ссылка содержит одноразовый секрет сопряжения. После импорта устройство хранит собственный токен клиента — отдельно от пароля интерфейса браузера — который переживает перезапуски сервера, пока вы его не отзовёте на выдавшем сервере.
