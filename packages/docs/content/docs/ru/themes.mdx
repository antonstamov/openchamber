# Темы

OpenChamber поддерживает встроенные темы и пользовательские JSON-файлы тем.

## Импорт темы VS Code

Откройте **Настройки → Внешний вид → Импорт темы VS Code**, чтобы выполнить поиск в Open VSX. В результатах показаны значок, название и автор. Выберите пакет, сравните предпросмотры цветов и импортируйте нужные варианты. Пакетный импорт сохраняет текущую тему активной. Open VSX — отдельный каталог; темы, опубликованные только в Microsoft Marketplace, могут не отображаться.

Используйте **Выбрать JSON-файл** для локального файла `.json` или `.jsonc` размером до 512 КиБ. Десктопное приложение открывает локальную папку `~/.vscode/extensions`, если она существует. OpenChamber преобразует цвета интерфейса, общей подсветки синтаксиса и diff, затем выбирает тему из файла и светлый или тёмный режим. Значок корзины рядом с импортированной темой в раскрывающемся списке удаляет её с подключённого сервера. Удаление выбранной темы восстанавливает значение по умолчанию для этого режима.

Тема сохраняется на подключённом сервере OpenChamber, в том числе при импорте с десктопа или мобильного устройства. Повторный импорт того же файла не создаёт дубликат и не перезаписывает тему, отредактированную на сервере. Расширение VS Code следует собственной теме VS Code.

Если файл использует `include` или ссылается на отдельный файл токенов, выполните **Developer: Generate Color Theme From Current Settings** в палитре команд VS Code и импортируйте сгенерированный JSON.

## Добавление пользовательской темы

1. Создайте каталог тем:

```bash
mkdir -p ~/.config/openchamber/themes
```

2. Скопируйте [JSON встроенной темы](https://github.com/openchamber/openchamber/tree/main/packages/ui/src/lib/theme/themes) или [стартовый пример](https://github.com/openchamber/openchamber/blob/main/docs/CUSTOM_THEMES.md#create-your-own-theme) в этот каталог как `my-theme.json`. Укажите уникальный `metadata.id` и собственное `metadata.name`, затем отредактируйте цвета.
3. Откройте **Настройки → Внешний вид**. OpenChamber подхватит новый файл в течение пары секунд.
4. Выберите тему в раскрывающемся списке. Она применится сразу.

Сохранённые правки отображаются так же, в каждом открытом окне. **Обновить темы** считывает папку сразу. Для светлой/тёмной пары создайте два файла с разными ID и задайте `metadata.variant` как `light` или `dark`. Выберите каждую в соответствующем раскрывающемся списке.

Начните с фонов, основного текста и акцента. Держите границы и выделенные строки приглушёнными, а встроенному коду дайте собственный читаемый цвет. Проверьте палитру в чате, настройках и diff. Пользовательский JSON сохраняет ваши явные цвета; автоматические корректировки, используемые при импорте из VS Code, к этим файлам не применяются.

## Расположение тем

- macOS/Linux: `~/.config/openchamber/themes/`

Эта папка принадлежит машине, на которой работает ваш сервер OpenChamber. Если вы подключаетесь к удалённому серверу, сохраните файлы там. При пользовательском каталоге данных OpenChamber используется собственная папка `themes`.
